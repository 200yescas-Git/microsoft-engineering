# Documentation

## Overview

Este directorio contiene la documentación técnica desarrollada dentro del dominio **Active Directory**.

Aquí se organizan conceptos, servicios, configuraciones, procedimientos y buenas prácticas relacionadas con la administración de identidades, servicios de directorio e infraestructura Microsoft empresarial.

---

## Purpose

El propósito de esta documentación es:

- Organizar conocimiento técnico del dominio.
- Consolidar conceptos relacionados con Active Directory.
- Documentar configuraciones y procedimientos administrativos.
- Servir como referencia para laboratorios y futuras implementaciones.

---

## Documentation Areas

La documentación puede incluir temas relacionados con:

- Active Directory Fundamentals.
- Active Directory Domain Services (AD DS).
- Domain Controllers.
- Users & Groups.
- Organizational Units (OU).
- Group Policy Objects (GPO).
- DNS Integration.
- Authentication.
- Permissions Management.
- Windows Server Administration.
- Hybrid Identity.
