# Active Directory

## Overview

Active Directory es un dominio enfocado en la administración de servicios de identidad, autenticación, autorización y gestión de recursos dentro de entornos empresariales basados en Microsoft Windows Server.

Este dominio reúne documentación técnica, laboratorios, rutas de aprendizaje y recursos orientados al desarrollo de competencias relacionadas con la administración de infraestructura Microsoft, servicios de directorio y gestión centralizada de usuarios y equipos.

---

## Purpose

El propósito de este dominio es desarrollar competencias relacionadas con:

- Identity Management.
- Windows Server Administration.
- Directory Services.
- Authentication & Authorization.
- Enterprise Infrastructure.

---

## Scope

Este dominio comprende las siguientes áreas:

- Active Directory Domain Services (AD DS).
- Domain Controllers.
- Users & Groups Management.
- Organizational Units (OU).
- Group Policy Objects (GPO).
- DNS Integration.
- Authentication Services.
- Permissions Management.
- Windows Server Administration.
- Enterprise Identity Management.
