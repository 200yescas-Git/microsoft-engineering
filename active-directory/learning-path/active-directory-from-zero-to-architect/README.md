# Active Directory Fundamentals

## Overview

Esta ruta de aprendizaje está basada en el curso **Active Directory de 0 a Arquitecto** de **Udemy**, orientado al desarrollo de competencias relacionadas con la administración de servicios de directorio, gestión de identidades y configuración de infraestructura Microsoft basada en Windows Server.

Su propósito es proporcionar una base sólida en Active Directory y preparar el camino hacia la administración avanzada de entornos empresariales, servicios híbridos e infraestructura Microsoft.

---

## Objective

El objetivo de esta ruta de aprendizaje es desarrollar competencias relacionadas con:
